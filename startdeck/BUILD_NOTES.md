# Build notes

## 0.3.1

Документационный релиз:

- собран подробный `README.md`;
- добавлены инструкции по загрузке проекта на GitHub;
- добавлен `.gitignore`, чтобы не залить `node_modules`, `dist`, локальные профили и приватные конфиги;
- версия обновлена до `0.3.1`;

## 0.3.0

- название изменено на StartDeck;
- дефолтный `data/apps.json` пустой и не содержит личных данных;
- добавлен безопасный пример `data/example-apps.json`;
- добавлена кнопка `+ Пример` в интерфейсе;
- пользовательский конфиг сохраняется через безопасное хранилище Electron, если оно доступно;
- при доступном шифровании используется `profiles.encrypted.json`;
- при недоступном шифровании используется обычный `profiles.json`;
- сохранён фикс `base: './'` для Vite, чтобы portable `.exe` не открывался пустым окном;
- меню Electron скрыто.

Сборка:

```powershell
npm install
npm run dist:win
```
